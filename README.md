# التحول الكيميائي

تطبيق محاكاة تفاعلي للتحولات الكيميائية، بلسانين: **التجربة** (احتراق الفحم داخل جرة زجاجية مع نفاد الأكسجين تدريجيًا، والتحليل الكهربائي للماء بتصاعد غازي H₂ وO₂ بنسبة 2:1)، مع عدسة مكبرة تعرض التفاعل ذرة بذرة؛ و**التعبير عن التحول الكيميائي** (سبورة تفاعلية بالسحب والإفلات لبناء المعادلة، بمستويين: غير موزونة للمتوسط الثاني، وموزونة مع عداد ذرات للمتوسط الثالث).

جزء من سلسلة محاكيات **PhysicLabDZ** التعليمية الموجهة للمنهاج الجزائري (الجيل الثاني).
